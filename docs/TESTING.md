# TGLite 测试说明

## GitHub Actions 自动测试

工作流程文件为 `.github/workflows/windows-release.yml`。使用 Windows Server 2025、Visual Studio 2026、.NET 10 和项目指定的依赖版本。只有测试成功才创建预发布版本。

自动测试覆盖以下内容：

1. 检查个人定制代码，确认频道、机器人聊天和视频播放器的广告获取入口已关闭，Premium 推广入口已隐藏，Telegram 登录参数仍然存在。
2. 检查 JavaScript 构建脚本、修改过的 C# 文件和 XAML 文件，并编译 TDLib 集成测试程序。
3. 从 GitHub Actions Secrets 读取 `API_ID`、`API_HASH` 和 `PFX`，检查证书有效期、代码签名用途、安装包 Publisher 以及私钥是否可用。
4. 构建 Windows x64 的 TDLib，调用其 JSON 接口检查本机动态库是否可以加载、版本信息是否可读取。
5. 在 Telegram 官方测试服务器创建临时测试账号，完成验证码验证，调用 `getMe`，向测试账号的 Saved Messages 发送一条测试消息并从历史记录中读取。测试账号采用 Telegram 保留的 `99966XYYYY` 号码，使用测试数据中心提供的固定验证码。
6. 编译 Windows x64 MSIXBundle，检查数字签名、签名证书指纹、安装包版本和安装包身份。
7. 在 GitHub Actions Windows 运行环境中安装 MSIXBundle、注册应用并尝试启动 `Telegram.exe`，检查进程是否保持运行。
8. 计算发布文件的 SHA-256，保存 `BUILD-INFO.json`、`TEST-RESULTS.json` 和 `SHA256SUMS.txt`，然后发布 GitHub Release。

测试服务器上的账号及消息仅用于开发测试，不保存个人账号的登录验证码、聊天记录或会话信息。编译使用的 PFX 私钥和 Telegram API 凭据只存在于 Actions 的运行环境中。

## Windows 人工功能测试

发布版本还应在正常使用的 Windows 11 设备上执行以下检查。各项功能应根据实际操作逐项记录结果：

| 功能 | 操作 | 预期结果 |
| --- | --- | --- |
| 首次安装 | 信任 Release 中的公开证书，安装 MSIXBundle | 安装正常，开始菜单存在 TGLite |
| 程序启动 | 通过开始菜单启动、关闭并再次打开 | 显示登录界面或已登录的聊天列表，无异常退出 |
| 账号登录 | 使用手机号码或二维码登录，必要时完成两步验证 | 正常进入个人账号，账号信息正确 |
| 消息同步 | 进入已有聊天，查看历史记录与未读消息 | 消息内容、顺序和未读状态正确 |
| 文字聊天 | 发送、回复、编辑、撤回消息 | 本机与另一台设备显示一致 |
| 媒体和文件 | 发送、下载和打开图片、视频、语音、文档 | 文件完整，媒体可以播放 |
| 群组和频道 | 加入、查看历史记录、发送有权限的消息 | 权限与服务器设置一致 |
| 通话 | 与测试联系人进行语音和视频通话 | 声音、画面、麦克风和摄像头权限正常 |
| 通知 | 在窗口最小化和关闭后测试新消息 | 通知显示符合系统设置 |
| 广告界面 | 查看公开频道、机器人会话以及频道视频 | 没有个人版本计划移除的广告组件 |
| 会员推广 | 检查设置、个人资料页和礼物界面 | 没有计划移除的 Premium 购买与推广入口 |
| Stars 礼物 | 查看礼物列表和已保存的 Stars 相关信息 | 可用功能正常，余额由 Telegram 服务器决定 |
| 更新安装 | 使用相同证书安装新版本 | 安装与会话数据保留符合预期 |

GitHub Actions Windows 运行环境可以检查程序安装与启动，但其自动化测试不会使用个人 Telegram 账号。个人账号登录、媒体通话、操作界面完整性及长期运行稳定性需要上述人工操作。

## 查看与保存测试结果

在仓库的 Actions 页面选择 `Build and release TGLite for Windows`，可以查看每次执行的具体步骤。成功发布的 Release 会附带 `TEST-RESULTS.json`，说明自动化测试结果以及需要人工检查的功能，`BUILD-INFO.json` 则包含上游提交、TGLite 源码提交、版本号和工作流程地址。

每次合并 Unigram 上游新版本后，必须重新执行全部自动化测试，并检查本文件中的人工测试项目。维护记录参见 [MAINTENANCE.md](MAINTENANCE.md)。
